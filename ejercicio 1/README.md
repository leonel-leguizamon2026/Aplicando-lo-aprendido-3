# 1) Generalización simbólica: ¿Cuáles son las reglas escritas del lenguaje?

-Objetos: permiten agrupar datos y comportamientos mediante propiedades y metodos.
-Propiedades: representan los datos almacenados dentro de los objetos.
-Metodos: son funciones asociadas a los objetos que permiten definir comportamientos.
-Prototipos: cada objeto puede estar relacionado con otro objeto, denominado prototipo, del cual puede heredar propiedades y metodos.
-Herencia: permite que un objeto utilice propiedades y metodos definidos en su prototipo.
-prototype: permite definir propiedades y metodos que pueden ser compartidos por las instancias creadas a partir de una funcion constructora.
-this: hace referencia al objeto sobre el cual se está ejecutando un método o al contexto correspondiente.
-Funciones constructoras: pueden utilizarse junto con new para crear nuevos objetos y establecer su prototipo.
-new: permite crear una nueva instancia a partir de una función constructora.
-Encapsulamiento: los datos y las operaciones relacionadas pueden mantenerse agrupados dentro de un mismo objeto.

# 2) Creencias de los profesionales: ¿Qué características particulares del lenguaje se cree que sean "mejores" que en otros lenguajes?

-Su flexibilidad para trabajar con objetos, ya que permite crear y modificar objetos de manera dinámica sin requerir una estructura de clases tradicional.
-El uso de prototipos para la reutilización de código.
-JavaScript permite agregar, modificar o eliminar propiedades y metodos de los objetos durante la ejecucion del programa, proporcionando un modelo mas dinamico.
